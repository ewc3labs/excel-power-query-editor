# slices

One document per slice, when the roadmap row is not enough.

Most slices never need one. Write a slice doc when the work needs a paragraph a table row cannot
hold — a design decision with rejected options, a sequence that has to happen in order, or evidence
worth keeping.

Name the file after the slice ID and its subject: `PQ-01_Tag_Triggered_Release_Pipeline.md`.

The roadmap row stays the source of truth for **state**. The slice doc holds the **why**.
